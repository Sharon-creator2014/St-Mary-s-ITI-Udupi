# St-Mary-s-ITI-Udupi
St. Mary's ITI (Udupi, Karnataka) is an NCVT-affiliated vocational institute founded in 1985. Managed by the Catholic Education Society of Udupi, it provides job-oriented technical training for SSLC pass students aged 14–40. It offers 1 to 2-year practical courses in Electrician, Fitter, Mechanic Motor Vehicle, and Mechanic Diesel trades.
